🏃‍♂️ Subway Surfers 3D Runner

A lightweight, full-screen, 3D endless runner game built with Three.js, Tailwind CSS, and the Web Audio API. Inspired by the classic arcade mobile game Subway Surfers, this application is fully self-contained in a single index.html file—making it zero-dependency and ready for instant deployment on GitHub Pages or any static web host.

✨ Features

Endless Procedural Track Generation: Infinite tracks featuring randomized trains, low jump hurdles, high roll barriers, front ramps, and gold coin formations.

Uncapped Infinite Speed Progression: Difficulty scales continuously—the further you run, the faster and more intense the speed becomes.

Power-Ups & Collectibles:

🛡️ Hoverboard Shield: Protects the runner from a single collision impact.

🧲 Coin Magnet: Automatically pulls nearby coins toward you.

⚡ 2x Multiplier: Doubles your score accumulation rate.

🚀 Jetpack: Launches your runner into the sky where you can collect floating sky-coin trails.

Procedural Sound FX Synthesizer: Uses the native browser Web Audio API to generate jump swooshes, coin chimes, roll sounds, power-up effects, and crash sounds without requiring external audio files.

Responsive Arcade HUD: Displays real-time score, gold coins collected, active power-up timers, speed indicators, and local storage high score tracking.

Cross-Platform Controls: Full support for desktop keyboard controls and mobile touch/swipe gestures.
